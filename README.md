# SideQuest — A New Way to Plan

A native SwiftUI + iMessage prototype that turns “we should hang out” into a plan. This iMessage extension analyzes conversations, curated suggestions, and user votes to coordinate activities and events that could be exported to the Calendar app.

## Use and Functionality

1. Open a conversation in iMessage. Click the (+) button and navigate to SideQuest.
2. Click **Analyze Recent Chat** and **Show 3 plans**.
3. Open **Good to know** to figure out details about each event.
4. Tap **Why it works for your friends** to see why each event was suggested.
5. Click the **Address** to navigate to the location on Apple Maps.
6. Vote **Down**, **Maybe**, or **Pass** for each event.
7. Click **Add to Calendar** to add the event to the Calendar app.
8. Lastly, tap **Share Final Plan** to share it to the group chat.
